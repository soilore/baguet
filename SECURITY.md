# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Soilore and the Baguet core engineering team take mathematical determinism, air-gapped security, and cryptographic integrity seriously.

If you believe you have discovered a vulnerability, security flaw, or cryptographic boundary weakness in the Baguet core engine or SDK, please report it privately:

- **Email:** [contact@soilore.com](mailto:contact@soilore.com)
- **Encryption:** GPG/PGP key available upon request or signed Ed25519 disclosure channel.

### Responsible Disclosure Guidelines
1. Do not open public GitHub issues or public pull requests for undisclosed vulnerabilities.
2. Provide actionable technical details, including reproduction steps, operating system, and payload samples.
3. Allow up to 48 hours for an initial response and acknowledgment from our DevSecOps team.
4. We coordinate patch verification and CVE assignment before public disclosure.
