Subprocessadores & Operação Air-Gapped

Inventário de subprocessadores e declaração formal de soberania operacional do Baguet v1.0.0.

1. Declaração de Zero Subprocessadores em Produção

O núcleo algorítmico do Baguet (Rust Core v8.9.5 e Python SDK v1.0.0) NÃO possui qualquer dependência de terceiros nem transfere dados para entidades externas durante as operações de compressão, busca vetorial ou inferência.

2. Serviços Opcionais de Faturamento

Exclusivamente na interface web pública ou autoatendimento comercial, a Stripe Inc. é utilizada como processadora de pagamentos para aquisição de licenças corporativas. Ambientes governamentais ou air-gapped utilizam ordens de compra diretas com zero integração cloud.
