Data Processing Addendum (DPA)

Termos de processamento e governança de dados do software Baguet v1.0.0. Este adendo estabelece os compromissos contratuais de proteção e privacidade de dados entre a Soilore e a entidade contratante (Cliente Enterprise).

1. Natureza da Operação e Zero-Cloud Guarantee

O motor algorítmico do Baguet opera exclusivamente de modo local e em memória nos nós computacionais do Cliente. Não há transmissão, ingestão, telemetria ou armazenamento de dados em servidores da Soilore.

2. Conformidade GDPR (Art. 28) e LGPD (Art. 39)

O Cliente é o único Controlador dos dados pessoais eventualmente contidos nos fluxos comprimidos. A Soilore não atua como Operadora/Processadora de dados de produção do Cliente uma vez que o software opera de forma estritamente licenciada on-premises.

3. Soberania Criptográfica e Segurança da Informação

Todos os dados sob o modo de autenticação BGT-AE são protegidos por primitivas autenticadas de alta segurança (Ed25519 e AES-256-SIV). O Cliente detém a custódia exclusiva das chaves de criptografia e licença.
