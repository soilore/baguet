BAGUET v1.0.0 — Guia técnico de instalação, uso e operação

Ecossistema de memória algébrica e compressão 100% sem perdas (lossless) projetado para executar buscas vetoriais, atenção e inferência diretamente sobre dados de IA comprimidos sem descompressão prévia — eliminando até 75% da sobrecarga de memória RAM e armazenamento com preservação matemática exata dos bits originais.

O que o BAGUET faz — e o que não promete

SEC.CAT-00.2

O BAGUET oferece:

  • [+]
    compressão e restauração universal de bytes com garantia matemática de integridade bit-exact via SHA-256;
  • [+]
    execução direta sobre dados comprimidos (Compute-on-Compressed-Data), incluindo KV cache de LLMs, embeddings para RAG, matrizes de pesos e checkpoints diferenciais;
  • [+]
    caminhos lossless dedicados para formatos de áudio, imagem e vídeo estruturados;
  • [+]
    contêineres indexados para acesso a registros em tempo O(1) e motor de streaming paralelo multi-bloco;
  • [+]
    governança criptográfica de licenças offline (Ed25519), recibos periciais e ferramentas locais de auditoria de ROI;
  • [+]
    uma interface visual e interativa local chamada BAGUET Studio.
DEFINIÇÃO FORMAL LOSSLESS RIGOROSO & LIMITES DA TEORIA DA INFORMAÇÃO
A designação lossless se aplica rigorosamente às operações que preservam a integridade integral dos dados originais e cuja restauração reproduz a mesma sequência de bits. Certos modos progressivos disponibilizam camadas base de menor precisão para inicialização rápida ou visualização; essas camadas são parciais e o refinamento exato permanece acessível sob demanda. Como em qualquer sistema de teoria da informação, dados de alta entropia ou já comprimidos podem apresentar pequeno acréscimo de cabeçalho.

O BAGUET não substitui um modelo de linguagem ou visão nem executa, por si só, o treinamento completo de redes neurais. Ele atua como o substrato de alta eficiência para armazenamento e computação sobre representações tensoriais e binárias.

1. Instalação e Canais de Distribuição

SEC.CAT-01

Requisitos de Sistema

  • [SYS]
    Python: Versão 3.11 ou superior (obrigatório para conformidade de tipagem e buffers nativos C-ABI).
  • [REQ]
    Dependências de Execução: numpy >= 1.24 e cryptography >= 41.
  • [OPT]
    Dependências Opcionais: torch >= 2.1 e ml_dtypes >= 0.3 (necessários apenas para integração direta com tensores PyTorch e suporte a BFloat16).
  • [ENV]
    Ambientes Homologados: macOS (Apple Silicon arm64 e Intel x86_64), Linux (glibc >= 2.31, x86_64 e aarch64) e Windows 10/11 (64-bit x64).

1.1 Instalação via Pip (Índice de Pacotes Python)

Para instalar a distribuição oficial com o motor nativo, a CLI e o BAGUET Studio:

CONSOLE // LINUX & macOS BASH bash 
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install baguet

No Windows (PowerShell):

CONSOLE // WINDOWS POWERSHELL powershell 
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install baguet

Instalação com suporte opcional a PyTorch

CONSOLE // PYTORCH EXTRA bash 
python -m pip install "baguet[torch]"

1.2 Instalação via Ecossistema Conda / Mamba

Para estações de trabalho de ciência de dados e clusters corporativos gerenciados via Conda:

CONSOLE // CONDA-FORGE bash 
# Criação do ambiente dedicado
conda create -n baguet-env python=3.11 -y
conda activate baguet-env

# Instalação a partir do canal conda-forge
conda install -c conda-forge baguet

(Nota de distribuição: a receita de empacotamento provisiona automaticamente as dependências binárias zlib, numpy >= 1.24 e cryptography >= 41, registrando o pacote sob o identificador canônico baguet-sdk com alias executável baguet).

1.3 Instaladores Desktop e Integração com o Sistema Operacional

Para usuários que preferem utilizar o BAGUET Studio integrado ao sistema operacional sem gerenciar ambientes virtuais pelo terminal:

  • [OSX]
    macOS Universal: pacote .dmg compatível com Apple Silicon (M1/M2/M3/M4) e Intel, incluindo Quick Action para o Finder.
  • [WIN]
    Windows x64: instalador executável com integração ao menu de contexto do Windows Explorer.
  • [LNX]
    Linux: pacote AppImage / entrada .desktop compatível com o padrão XDG.

Caso você já tenha instalado o pacote via Pip ou Conda, gere os arquivos e atalhos de integração com o botão direito do seu sistema operacional executando:

CONSOLE // DESKTOP PROVISIONING bash 
baguet install-desktop --target-dir ./integracao-baguet

1.4 Confirmar a Instalação

Valide se o SDK e o núcleo nativo estão operacionais:

CONSOLE // VERIFICAÇÃO OPERACIONAL bash 
python -c "from baguet_sdk import core; engine = core.BaguetEngine(); print('BAGUET pronto')"
baguet self-test

O motor carrega o backend compilado em Rust por padrão, ativando aceleração SIMD AVX2/FMA em processadores x86_64 ou NEON em arquiteturas ARM64. O auto-teste (self-test) executa uma bateria determinística que valida todos os subsistemas criptográficos e tensoriais em milissegundos.

2. Primeiro uso com Python

SEC.CAT-02

A fachada pública baguet_sdk disponibiliza cinco namespaces estruturados: core, ai, media, license e studio. O exemplo abaixo demonstra a compressão e restauração com verificação de integridade:

PYTHON // EXEMPLO FUNDAMENTAL python 
from baguet_sdk import core

engine = core.BaguetEngine()
original = b"Dados de exemplo para o primeiro uso do BAGUET."

packet, useful_bits = engine.compress_bytes(original)
restored = engine.decompress_bytes(packet)

assert restored == original
print(f"Entrada: {len(original)} B; pacote: {len(packet)} B; bits uteis: {useful_bits}")

compress_bytes retorna uma tupla: o pacote binário compactado e a quantidade de bits úteis codificados. decompress_bytes retorna os bytes exatos restaurados. Recomenda-se criar uma instância única de BaguetEngine para compartilhar configurações, licenças e limites ao longo da aplicação.

O namespace também permite chamadas funcionais diretas passando engine=engine:

PYTHON // CHAMADA FUNCIONAL DIRETA python 
from baguet_sdk import core

engine = core.BaguetEngine()
packet, bits = core.compress_bytes(b"amostra", engine=engine)
restored = core.decompress_bytes(packet, engine=engine)

Hierarquia de Exceções do BAGUET

  • [EXC]
    BaguetError: classe-base para exceções operacionais do protocolo.
  • [WARN]
    BaguetContingencyWarning: aviso emitido quando uma contingência não-fatal ocorre.
  • [FAIL]
    BaguetIntegrityError: disparado quando um pacote está malformado, truncado ou com hash SHA-256 divergente (fail-closed).
  • [SEC]
    BaguetSecurityError: disparado quando uma política de segurança, chave BGT-AE ou licença é violada.
  • [PRIOR]
    BaguetPriorMismatchError: o prior de domínio informado difere daquele exigido pelo arquivo.
  • [NOTF]
    BaguetNotFoundError: o registro ou chave solicitada não existe no contêiner (compatível com KeyError).

4.1 Bytes, envelopes e inspeção

PYTHON // CORE BYTES & ENVELOPES python 
from baguet_sdk import core

engine = core.BaguetEngine()
raw = b"conteudo de producao para arquivamento"
packet, bit_count = engine.compress_bytes(raw)
assert engine.decompress_bytes(packet) == raw

# Envelopamento web autonomo
html_envelope = core.BaguetShareableEnvelope.pack_html(packet, locale="pt")
assert core.BaguetShareableEnvelope.unpack_html(html_envelope) == packet

Para inspecionar metadados de qualquer contêiner em tempo O(1) sem descomprimir seu conteúdo:

PYTHON // INSPEÇÃO DE CABEÇALHO O(1) python 
from baguet_sdk import core

# Cria um contêiner de exemplo para inspeção imediata
pacote, _ = core.compress_bytes(b"dados de telemetria do motor BAGUET")
with open("arquivo.bgt", "wb") as f:
    f.write(pacote)

info = core.inspect_file_info("arquivo.bgt")
print(f"Formato: {info.get('container')} | Acelerador: {info.get('accelerator')}")

4.2 IA: tensores e KV cache

PYTHON // KV CACHE COMPRESSION python 
import numpy as np
from baguet_sdk import core, ai

engine = core.BaguetEngine()
kv = np.arange(2 * 8 * 16, dtype=np.float16).reshape(2, 8, 16)

packet, bits = ai.compress_kv_cache(kv, engine=engine)
restored = ai.decompress_kv_cache(packet, engine=engine)

assert restored.shape == kv.shape
assert restored.dtype == kv.dtype
assert restored.tobytes() == kv.tobytes()

TENSOR IEEE 754 (FP16 / BF16 / FP32): [ S | E E E E E | M M M M M M M M M M ] -> 1 Bit Sinal + 5 Bits Expoente + 10 Bits Mantissa | v +-------------------------------------------------------------------------------------------------+ | PLANO DE BITS 0 (SINAL): [ S0 S1 S2 ... 4.3 IA: embeddings e busca Top-K sub-linear

Para garantir alinhamento com os registradores vetoriais SIMD do motor de busca, matrizes de embeddings para busca e sketch index devem ser criadas em np.float16 ou bfloat16:

PYTHON // TOP-K VETORIAL SUB-LINEAR python 
import numpy as np
from baguet_sdk import core, ai

engine = core.BaguetEngine()
# Embeddings FP16 (128 vetores de 32 dimensoes)
embeddings = np.random.default_rng(7).normal(size=(128, 32)).astype(np.float16)
query = np.random.default_rng(8).normal(size=(32,)).astype(np.float32)

packed, _ = ai.compress_embeddings(embeddings, engine=engine)
restored = ai.decompress_embeddings(packed, engine=engine)
assert np.array_equal(restored, embeddings)

# 1. Busca vetorial top-k direta sobre dados comprimidos
indices, scores = ai.search_compressed_embeddings_topk(
    packed, query, k=5, metric="dot", engine=engine
)

# 2. Construcao de sketch index e busca sub-linear com poda exata de subespacos
sketch = ai.build_embedding_sketch_index(packed, block_size=16, engine=engine)
pruned_indices, pruned_scores = ai.query_compressed_embeddings_topk(
    packed, query, k=5, metric="dot", sketch_index=sketch, engine=engine
)

4.4 IA: atenção em KV compactado e Offloader

PYTHON // ATENÇÃO KV DIRETA python 
import numpy as np
from baguet_sdk import core, ai

engine = core.BaguetEngine()
keys = np.ones((1, 8, 16), dtype=np.float16)
values = np.arange(1 * 8 * 16, dtype=np.float16).reshape(1, 8, 16)
query = np.ones((1, 16), dtype=np.float32)

key_packet, _ = engine.compress_kv_cache(keys)
value_packet, _ = engine.compress_kv_cache(values)

context, weights = ai.compressed_kv_attention_forward(
    key_packet, value_packet, query, engine=engine
)

Para gerenciar blocos de contexto histórico com armazenamento intermediário sob demanda:

PYTHON // KV CACHE OFFLOADER python 
import numpy as np
from baguet_sdk import core, ai

engine = core.BaguetEngine()
offloader = ai.BaguetKVCacheOffloader(engine=engine)
offloader.put_block(0, np.ones((8, 16), dtype=np.float16), np.ones((8, 16), dtype=np.float16))
keys, values = offloader.get_block(0)
context, weights = offloader.attention_on_offloaded_blocks(
    [0], np.ones((16,), dtype=np.float32)
)

4.5 IA: camadas lineares comprimidas

PYTHON // CAMADA LINEAR NUMPY python 
import numpy as np
from baguet_sdk import ai, core

engine = core.BaguetEngine()

4.6 IA: SafeTensors, delta e tensores progressivos

PYTHON // SAFETENSORS & DELTA CHECKPOINT python 
import numpy as np
from baguet_sdk import core, ai

engine = core.BaguetEngine()
base = {"layer.weight": np.zeros((4, 4), dtype=np.float32)}
updated = {"layer.weight": np.ones((4, 4), dtype=np.float32)}

# Empacotamento de dicionario
archive, _ = ai.compress_safetensors_dict(updated, engine=engine)
all_tensors = ai.decompress_safetensors_dict(archive, engine=engine)

# Checkpoint diferencial reversivel (BGTD6)
delta, metadata = ai.compress_safetensors_delta(updated, base, engine=engine)
reconstructed = ai.decompress_safetensors_delta(delta, base, engine=engine)

# Tensor progressivo (BGTP6)
progressive, progressive_metadata = engine.compress_tensor_progressive(
    updated["layer.weight"], trim_mantissa_bits=16
)
preview = engine.decompress_tensor_progressive(progressive, full_precision=False)
exact = engine.decompress_tensor_progressive(progressive, full_precision=True)
assert np.array_equal(exact, updated["layer.weight"])

Transcodificação reversível de contêineres:

PYTHON // TRANSCODIFICAÇÃO BGTU6 python 
import gzip
from baguet_sdk import core, media

engine = core.BaguetEngine()
dados_brutos = b"conteudo do log arquivado"
source_container = gzip.compress(dados_brutos)
packet, metadata = media.transcode_compressed(source_container, engine=engine)

# Reconstrução do contêiner com descompressão bit-exact nos dados originais
restored_container = media.untranscode_compressed(
    packet, reconstruct_container=True, engine=engine
)
assert gzip.decompress(restored_container) == dados_brutos

# Ou extração direta do payload bruto descompactado
restored_raw = media.untranscode_compressed(
    packet, reconstruct_container=False, engine=engine
)
assert bytes(restored_raw) == dados_brutos

5. Interface de linha de comando (CLI)

SEC.CAT-05

Consulte baguet --help ou baguet COMANDO --help para inspecionar todas as opções.

Operações fundamentais de arquivo

CLI // OPERAÇÕES FUNDAMENTAIS bash 
# Comprimir arquivo para .bgt
baguet compress entrada.bin saida.bgt

# Descomprimir com validacao de hash SHA-256
baguet decompress saida.bgt restaurada.bin

# Inspecionar cabecalho O(1) de qualquer arquivo Baguet
baguet info saida.bgt

Modo rápido, envelope compartilhável e recibo pericial

CLI // PIPELINE RÁPIDO & CERTIFICADOS bash 
# Modo rapido para pipelines de alto throughput
baguet compress entrada.bin saida.bgt --fast-mode

# Envelope HTML compartilhavel (abre em qualquer navegador sem software instalado)
baguet compress entrada.bin saida.bgt.html --shareable

# Comprimir emitindo recibo pericial assinado (.baguet.receipt.json)
baguet compress entrada.bin saida.bgt --receipt

# Verificar autenticidade e roundtrip de um recibo
baguet verify-receipt saida.bgt.baguet.receipt.json --input-file entrada.bin --packet-file saida.bgt

Transcodificação multimídia reversível (BGTU6)

O transcodificador analisa a estrutura interna de contêineres e imagens pré-comprimidas (PNG RGB 8-bit sem entrelaçamento, áudio WAV PCM16, arrays NPY e arquivos .gz / .zlib) e reorganiza os fluxos em contêineres .bgtu com restauração bit-exact:

CLI // TRANSCODIFICAÇÃO BGTU6 bash 
baguet transcode documento.png documento.bgtu
baguet untranscode documento.bgtu restaurado.png --reconstruct-container

Prior de domínio, cofre de objetos e streaming

CLI // SLAB & STREAMING bash 
# Treinar prior contextual sobre arquivos de exemplo
baguet train-prior dominio.bgtpr amostra1.txt amostra2.txt

# Inserir e extrair de um cofre Slab (.bgtv) em O(1)
baguet slab-put cofre.bgtv "documento/1" entrada.txt
baguet slab-get cofre.bgtv "documento/1" restaurado.txt

# Streaming paralelo de arquivos grandes (>10 GB) com workers multi-core
baguet stream-compress arquivo-grande.bin arquivo-grande.bgts --chunk-size 4194304 --workers 4
baguet stream-decompress arquivo-grande.bgts restaurado.bin --workers 4

Auditoria de ROI e ativação de licença

CLI // AUDITORIA & LICENÇAS bash 
# Auditoria deterministica de reducao e projecao de economia
baguet roi-audit ./dataset --scale-tb 10.0 --json

# Consultar status da licenca ativa
baguet license status

# Ativar licenca offline BGTL1 (persiste em ~/.baguet/license.key)
baguet license activate "$BAGUET_LICENSE_TOKEN"

Criptografia autenticada (BGT-AE / AES-256-SIV)

CLI // CRIPTOGRAFIA AUTENTICADA BGT-AE bash 
# Comprimir protegendo com chave simetrica de 256 bits
baguet compress dados.csv cofre.bgt --key "sua-chave-secreta-de-producao"

# Descomprimir exigindo autenticacao
baguet decompress cofre.bgt restaurado.csv --key "sua-chave-secreta-de-producao"

# Ativar o modo de producao restrita (recusa formatos legados ou sem chave)
baguet compress dados.csv cofre.bgt --key "sua-chave-secreta-de-producao" --production

O BAGUET Studio é a interface visual nativa do ecossistema, operando como um painel web local seguro em loopback (127.0.0.1). Ele elimina intermediários e permite controlar todas as capacidades do motor.

6.1 Como Iniciar o Studio

No terminal, execute:

CONSOLE // START STUDIO bash 
baguet studio

O comando inicia o serviço local na porta padrão 8765 e abre automaticamente seu navegador em:
http://127.0.0.1:8765/

Opções de Inicialização:

  • baguet studio --host 127.0.0.1: especifica o endereço IP local de escuta (padrão seguro 127.0.0.1).
  • baguet studio --port 8765: define uma porta TCP personalizada caso a 8765 esteja ocupada por outro serviço.
  • baguet studio --no-browser: executa o serviço sem disparar a janela do navegador automaticamente (ideal para servidores remotos, containers Docker ou acesso via túnel SSH).
  • baguet studio --once: atende a uma única sessão de uso e encerra o processo do servidor local automaticamente.
AVISO OPERACIONAL MODO DE DEMONSTRAÇÃO VS AMBIENTE DE PRODUÇÃO
Modo de Demonstração: abrir studio/index.html diretamente pelo protocolo file:// sem iniciar o comando baguet studio impede o acesso seguro às APIs locais do sistema operacional. Nessa condição, a interface opera em modo estático de demonstração. Para processar seus arquivos de produção, inicie sempre através do comando baguet studio.

6.2 Navegação Global, Idiomas e Atalhos de Teclado

  • Atalhos Rápidos de Teclado: Pressione as teclas numéricas 1, 2, 3, 4 ou 5 para saltar instantaneamente entre os Halls.
  • Paleta de Comandos ([ ⌘K ] ou Ctrl+K): Abre a busca rápida para acionar auditorias, disparar o auto-teste (self-test) ou inspecionar recibos recentes apenas digitando.
  • Seletor de Idioma (i18n): No canto superior direito, alterne em menos de 1 ms entre 7 idiomas completos: EN (Inglês), PT (Português), ES (Espanhol), DE (Alemão), FR (Francês), ZH (Chinês) e JA (Japonês). A preferência é salva localmente em ~/.baguet/preferences.json.
  • Rodapé de Instrumentação: Exibe o status do acelerador vetorial (AVX2/FMA ou NEON), latência FFI da última operação em microssegundos e garantia de proteção contra CSRF.
SALA 01 — ROI & Audit (01 / ROI & AUDIT)

SALA 02 — Compressor & Transcoder (02 / COMPRESSOR)
[MOTOR LOSSLESS]

Objetivo: Compactar, descompactar e transcodificar arquivos com precisão matemática integral.

1
Carregar o Arquivo: Arraste e solte o arquivo desejado sobre o plinto central de Drag & Drop ou clique para selecionar.
2
Escolha a Operação:
  • Compress File: compacta qualquer arquivo regular gerando o contêiner .bgt.
  • Restore Original: descomprime um arquivo .bgt validando a integridade por SHA-256.
  • Convert File: transcodifica formatos pré-comprimidos (PNG, WAV, NPY, gzip) para .bgtu.
  • Restore Original Format: reverte o contêiner .bgtu ao arquivo original de forma bit-exact.
3
Interruptores de Precisão:
  • Authenticated Encryption (AES-256-SIV): adiciona proteção criptográfica militar (requer Tier Growth ou chave informada).
  • Issue Bit-Exact Delivery Certificate: gera um certificado assinado Ed25519 com os hashes de entrada e saída.
  • Export Standalone Web Archive (.bgt.html): encapsula o pacote em uma página web auto-extraível.
  • Real-Time Fast Mode (~1.8 GiB/s): prioriza velocidade para pipelines de alta vazão.
4
Clique em EXECUTE COMPRESSION ENGINE.
5
Ao concluir, utilize os botões DOWNLOAD RESULT e VIEW RECEIPT.
SALA 03 — Slab & Stream (03 / SLAB & STREAM)
[CONTÊINERES & VAZÃO]

Objetivo: Inspecionar formatos em tempo O(1), gerenciar bancos em arquivo único e executar streaming multi-thread.

  • Inspetor Universal de Formatos: Selecione qualquer arquivo .bgt* e clique em INSPECT FILE para visualizar metadados estruturais, versão e assinatura do cabeçalho sem descompactar o arquivo.
  • Instalação no Sistema Operacional: Clique em INSTALL TO CONTEXT MENU & DESKTOP SHORTCUT para provisionar as extensões de clique direito no macOS, Windows ou Linux.
  • Indexed Object Vault (Slab Pool .bgtv):
    1. Informe o caminho do cofre (ex.: meu_banco.bgtv).
    2. Clique em LIST para ver as chaves cadastradas.
    3. Arraste um arquivo no Compressor e use + INSERIR OBJETO (PUT) informando a chave lógica (ex.: layer0.weights).
    4. Recupere qualquer objeto em tempo O(1) pelo botão GET O(1) ou remova com DEL.
  • Motor de Streaming Paralelo:
    1. Especifique arquivo de entrada e destino .bgts.
    2. Ajuste o tamanho do bloco (64 KB a 4 MB) e a quantidade de workers (1 a 64).
    3. Execute RUN STREAM COMPRESSION ou DECOMPRESS STREAM.
SALA 04 — AI & LLM Studio (04 / AI KERNELS)
[COMPUTE-ON-COMPRESSED-DATA]

Objetivo: Simular e inspecionar a execução direta sobre dados comprimidos (Compute-on-Compressed-Data).

1
Selecione o Perfil Matemático:

  • Online Flash-SDPA Attention (Modo 9): cálculo de atenção diretamente sobre fatias de KV-Cache comprimidas.
  • Zero-Copy KV-Cache Offloader: swap estruturado com paged attention sob demanda.
  • Direct Compressed Linear Projection: produto matricial W · x + b sem inflar tensores inteiros na memória.
  • Progressive Tensor & AllReduce (BGTP6): separação em camada base e refinamento residual.
  • Differential Fine-Tuning Checkpoint (BGTD6): deltas matriciais exatos para LoRA e checkpoints.
2
Defina o tamanho do tensor de teste (na licença gratuita Community, o limite do sandbox é de 16 MB).

Clique em RUN LIVE AI BENCHMARK.

O Studio renderiza o diagrama vetorial cinético ilustrando a decomposição ortogonal de planos de bits (Sign, Exponent e Mantissa) e disponibiliza o trecho de código Python pronto para cópia ([ ⌘C ]).

8.3 Variáveis de Ambiente e Blindagem Operacional

O ecossistema BAGUET suporta um conjunto auditado de variáveis de ambiente para orquestração em contêineres, clusters de alta criticidade e mitigação de vulnerabilidades em dependências nativas de terceiros:

Variável de Ambiente Valores / Tipo Finalidade e Comportamento Operacional
BAGUET_LICENSE_TOKEN String (BGTL1) Token criptográfico Ed25519 para ativação offline de licenças Pro, Growth ou Enterprise em ambientes sem disco persistente (Docker / Kubernetes / CI).
BAGUET_REQUIRE_PATCHED_BROTLI "1" / "0" Mitigação defensiva contra a vulnerabilidade CVE-2026-111497 (Brotli HTTP2Shell / Broccoli2Shell). Quando definida como "1", o motor exige biblioteca C brotli >= 1.2.1 para desembrulhar fluxos pré-compactados em _unwrap_precompressed_stream; versões anteriores são tratadas com segurança como raw sem alimentar o descompressor C vulnerável.
BAGUET_DISABLE_BROTLI_PROBE "1" / "0" Desativa completamente qualquer tentativa de probe ou descompressão de fluxos Brotli, retornando imediatamente os dados brutos como raw.
BAGUET_HOME Caminho (Diretório) Define o diretório base para armazenamento de licenças locais, leases de nó e preferências (padrão: ~/.baguet).
BAGUET_LANG "en" | "pt" | ... Sobrescreve a detecção automática de idioma do sistema operacional para a CLI e o Studio (suporte a 7 idiomas).
BAGUET_NODE_ID String Identificador de nó explícito para contabilização e liberação em gerenciamento de leases concorrentes flutuantes (Floating Node Leases).

10. Resolução de problemas (Troubleshooting) & FAQ

SEC.CAT-10

Tabela de Diagnóstico e Resolução de Erros

Sintoma / Erro Causa Provável Ação de Resolução
ImportError: cannot import name 'baguet_sdk' Ambiente Python incorreto ou pacote ausente Ative o ambiente virtual correto (source .venv/bin/activate); confirme a instalação com python -m pip show baguet.
Erro de núcleo Rust nativo ausente Pacote sem biblioteca nativa compilada para a arquitetura Instale a versão oficial para seu sistema (x86_64 ou arm64). Não copie bibliotecas dinâmicas (.so/.dylib/.dll) entre sistemas operacionais diferentes.
BaguetIntegrityError: Violação de integridade detectada Arquivo truncado, corrompido em disco (bit-rot) ou com hash SHA-256 divergente O motor opera em modo fail-closed. Verifique o tamanho do arquivo, confira o backup e inspecione o cabeçalho executando baguet info <arquivo>.
BaguetSecurityError: Bomba de descompressão bloqueada Saída excede o teto de segurança em memória (MAX_DECOMPRESSED_BYTES, padrão 64 MB) Para arquivos volumosos, utilize o motor de streaming paralelo (baguet stream-compress) ou instancie o motor elevando o teto: BaguetEngine(max_decompressed_bytes=1024*1024*1024).
BaguetSecurityError: Pacote marcado como keyed exige chave BGT-AE Arquivo gravado com criptografia autenticada (AES-256-SIV) e a chave simétrica não foi fornecida Forneça a chave correspondente: baguet decompress arquivo.bgt restaurado.bin --key "sua-chave" ou no SDK: BaguetEngine(license_key=b"sua-chave").
BaguetSecurityError: Token BGTL1 inválido ou expirado Assinatura do token inválida, chave não confiável ou prazo expirado fora da carência Verifique se a data do sistema está correta e solicite a renovação da credencial; durante o período de carência (grace period), o motor continua operando normalmente.
BaguetPriorMismatchError: Prior incompatível Arquivo foi compactado com um dicionário de domínio específico que não foi fornecido na restauração Forneça o arquivo .bgtpr original utilizado durante a compressão: baguet decompress arquivo.bgt saida.bin --prior dominio.bgtpr.
Address already in use ao iniciar o Studio A porta local 8765 está sendo utilizada por outra instância Especifique uma porta alternativa: baguet studio --port 9000.
Studio desconectado ou em modo demonstração Página foi aberta como arquivo estático (file://) em vez de iniciar o servidor Inicie pelo terminal com baguet studio e acerte a URL http://127.0.0.1:8765/ no navegador.
CVE-2026-111497 / Brotli HTTP2Shell Fluxo malformado acionando invalid block switch ou loop de buffer em libbrotli desatualizada (< 1.2.1) O BAGUET inclui guarda multi-bloco com teto de 64 KiB e trava anti-stall que aborta com segurança para raw. Perguntas Frequentes (FAQ)

FAQ // QUESTÃO 01 ACESSO A DADOS & CANCELAMENTO
P: Os arquivos comprimidos com o BAGUET podem se tornar inacessíveis caso a empresa cancele a assinatura?
R: Não. Todas as rotinas de leitura, descompressão universal (.bgt), reversão de contêineres (.bgtu) e mapeamento em memória (mmap) são regidas pela licença de código aberto permissiva MIT. Você tem a garantia contratual e técnica de acessar e descompactar seus dados para sempre sem custos adicionais.
FAQ // QUESTÃO 02 INTEGRIDADE EM MODELOS DE IA
P: O BAGUET altera em alguma casa decimal os pesos de modelos de IA?
R: Não. O BAGUET opera com reconstrução 100% bit-exact. Os tensores restaurados retornam rigorosamente os mesmos bits IEEE 754 originais, validados automaticamente por assinatura SHA-256.
FAQ // QUESTÃO 03 SIGILO & CONFORMIDADE REGULATÓRIA
P: É seguro utilizar o BAGUET com dados confidenciais ou protegidos por sigilo (LGPD, GDPR, HIPAA)?
R: Sim. O BAGUET opera 100% localmente no hardware da sua empresa, sem chamadas externas para a internet e sem telemetria. Para proteção contra vazamentos em repouso, o motor oferece a blindagem BGT-AE (AES-256-SIV — RFC 5297) com derivação HKDF-SHA256.
FAQ // QUESTÃO 04 LIMITES MATEMÁTICOS DE COMPRESSÃO
P: O BAGUET sempre reduz o tamanho de qualquer arquivo?
R: Não. Nenhum algoritmo de compressão sem perdas matematicamente viável pode reduzir qualquer sequência arbitrária de bytes (pelo Princípio da Casa dos Pombos). Para dados já compactados ou totalmente aleatórios, a saída pode manter o tamanho original com um acréscimo mínimo de cabeçalho.
FAQ // QUESTÃO 05 EXPIRAÇÃO DE ASSINATURA & CARÊNCIA
P: O que acontece quando a licença de produção expira?
R: O motor ativa o período de carência (grace period) embutido criptograficamente no token (7 dias para Pro, 15 dias para Growth e 90 dias para Enterprise), mantendo todas as operações ativas enquanto emite avisos em log. Mesmo após o encerramento do grace period, todas as rotinas de leitura e descompressão continuam livres e ilimitadas.
FAQ // QUESTÃO 06 BLINDAGEM DE SUPPLY-CHAIN & MITIGAÇÃO CVE-2026-111497
P: Como o BAGUET protege contra vulnerabilidades em compressores legados externos (ex.: CVE-2026-111497 / Brotli HTTP2Shell)?
R: O motor nativo em Rust do BAGUET é 100% isolado e imune a essa falha. Na camada de pré-desempacotamento de codecs de terceiros, o BAGUET implementa uma guarda multi-bloco com trava anti-stall que detecta payloads maliciosos e aborta imediatamente para o modo raw seguro. Em ambientes de alta segurança, a variável BAGUET_REQUIRE_PATCHED_BROTLI=1 exige libbrotli >= 1.2.1 e BAGUET_DISABLE_BROTLI_PROBE=1 desativa completamente o desempacotador Brotli.

11. Glossário rápido

SEC.CAT-11
  • [GL-01]
    Lossless: Reconstrução que reproduz rigorosamente a mesma sequência de bits e bytes originais, validada por conferência de integridade SHA-256.
  • [GL-02]
    Compute-on-Compressed-Data: Execução de operações matemáticas (busca vetorial, atenção e álgebra linear) diretamente sobre os dados em seu formato compactado, sem descompressão prévia.
  • [GL-03]
    KV Cache: Tensores de chaves e valores acumulados durante a inferência sequencial de modelos de linguagem (LLMs).
  • [GL-04]
    Sketch Pruning: Poda geométrica de subespaços vetoriais com limites exatos de Cauchy-Schwarz, descartando blocos irrelevantes sem necessidade de cálculo denso.
  • [GL-05]
    Virtual Slab Pool: Cofre em arquivo único que organiza múltiplos registros ou arquivos lógicos com recuperação e validação em tempo O(1).
  • [GL-06]
    Prior de Domínio: Matriz estatística contextual treinada em amostras reais de dados para otimizar a entropia de fluxos repetitivos.
  • [GL-07]
    BGT-AE: Camada de criptografia autenticada determinística baseada no algoritmo AES-256-SIV (RFC 5297) com derivação de chaves HKDF-SHA256 (RFC 5869).
  • [GL-08]
    Loopback: Endereço de rede local restrito estritamente à própria máquina hospedeira (127.0.0.1), impedindo conexões externas não autorizadas.

Pesos de modelos e tensores PyTorch

PYTHON // MODEL WEIGHTS & TORCH TENSORS python 
import numpy as np
from baguet_sdk import core

engine = core.BaguetEngine()
weights = {
    "layer.weight": np.arange(16, dtype=np.float16).reshape(4, 4),
    "layer.bias": np.zeros((4,), dtype=np.float32),
}
model_packet, bits = engine.compress_model_weights(weights)
restored_weights = engine.decompress_model_weights(model_packet)
assert np.array_equal(restored_weights["layer.weight"], weights["layer.weight"])

tensor = np.arange(32, dtype=np.float16).reshape(2, 4, 4)
tensor_packet, tensor_bits = engine.compress_torch_tensor(tensor)
restored_value = engine.decompress_torch_tensor(tensor_packet)
restored_tensor = restored_value.detach().cpu().numpy() if hasattr(restored_value, "detach") else restored_value
assert np.array_equal(restored_tensor, tensor)
